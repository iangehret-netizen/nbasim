# NBA Dynasty

A phone-first NBA coaching dynasty sim. Start in the 2003 offseason (the LeBron era), coach games live by quarter or sim them, and run the front office: draft, trades, free agency, contracts, and player development. Real rosters, real draft classes, and real-life moves play out around you.

## Put it on GitHub Pages
1. Create a new public repository.
2. Upload `index.html` (and this README) to the root.
3. Settings → Pages → Deploy from a branch → `main` / root → Save.
4. Open the link GitHub gives you. On iPhone, Share → Add to Home Screen.

Saves are stored in the browser you play in. Use Coach → Saves → Export to move a dynasty between devices.

Ratings are estimates based on real careers, not official 2K ratings. No league or team logos are used.
